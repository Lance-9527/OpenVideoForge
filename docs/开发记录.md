FilmGrade.apply(ctx, srcCanvas, w, h, {contrast,saturation,bloom,grain,vignette,letterbox,warmth})
  → 基础调色 → 辉光 halation → 暖高光/冷阴影 → 暗角 → 胶片颗粒 → 画幅遮幅
```

- 用到它的地方：右上角**成片预览小窗**、`editor.captureThumb()`（抓图/渲染 PNG/分镜表/片库缩略图全部走它）
- 新增控制（右栏「后处理」页底部）：**成片开/关**、**辉光 0–100%**、**颗粒 0–30%**、**画幅 关 / 1.85 / 2.39**
- 指令层同步：`grade.set {bloom, grain, letterbox, film}`；`state.get` 里带 `film`
- 关掉成片后回到纯白膜直出（写引用图、做尺寸比对时用）

实测（通过 Agent 桥 `render {w:800,h:450,returnBase64:true}` 出图）：导出 JPEG 带 2.39 遮幅、暖调、暗角、颗粒、辉光 —— 与右上角小窗一致。

### v1.0 AI 操作 + 用户操作 双通道（`js/studio-agent.js` + `server/agent-bridge.mjs`）

产品最终形态：**所有能力都是一条具名指令**，人和 AI 走同一套实现。

```
① 人：右最侧「AI 指令」窗（自然语言关键词解析 / 直接发 JSON）→ 指令总线 → 结构化反馈
② Agent(HTTP)：POST http://127.0.0.1:8787/cmd {name,args}

- 指令总线：`window.WB_AGENT.run(name,args) → {ok,data|error}`，`WB_AGENT.commands()` 列出 **24 条**指令（state/env/asset/light/grade/shot/camera/render/panorama/scene/storyboard…）

### 顺手修掉的 3 个上游 bug
1. **点「全景/中景/近景/特写」必现黑屏**：`setShotSize()` 只传 `{r}`，`_animateCam()` 拿 `undefined` 去插值，`phi/theta` 变 `NaN` → 相机位置全 `NaN` → 3D 画面整块消失且回不来。已给插值加缺省回落 + `_applyCamera()` 加 NaN 安全网。（`js/editor.js`）

## 5. 已知限制

1. **缩略图不持久化**：刷新后时间线卡片显示编号占位（重开场景后点镜头可重新抓）；缩略图是 JPEG dataURL，进 localStorage 会撑爆配额。要保留需换 IndexedDB。
2. **接触表不分页**：镜头多时是一张长图（约 60 镜 ≈ 4300px 高）。
3. **没有拖拽排序**：用左右箭头（为键盘无障碍刻意如此）。
4. **转场只有插值**：没有硬切；要硬切可把相邻两镜头机位设成一样、时长 0.1s。
5. **3D 视口底色仍由环境决定**（`scene.background`），CSS 的 `--pane-bg` 只在画布外可见；明暗主题下取景框都是环境天空色。
6. **移动端未适配**：轨道相机/拖拽按键鼠设计。
7. **导入的白膜 HTML 会执行脚本**，且 iframe 未加 `sandbox`（上游已知安全坑，建议后续加 `sandbox="allow-scripts"`）——只导入可信来源。
